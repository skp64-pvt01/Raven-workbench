Raven Workbench

A small desktop application built with Raven: a menu bar, a toolbar, a side bar, a status bar, an application page and an instrument panel.

Getting around

The central area is one pane at a time. Pick a pane with the side bar, with the View menu, or with a shortcut. The pane you leave keeps its state: the instrument panel goes on showing the same trend when you come back to it.

The instrument panel

A small simulated plant: the pump charges a pressure vessel, the valve lets flow through, and the interlocks trip the alarm above a threshold.

  • Pressure gauge — needle, ticks, and an arc filled to the value. The needle turns red above the alarm threshold.
  • Flow meter — the digital readout and its bar.
  • Lamps — power, link, alarm. The alarm lamp is lit when the interlocks are armed and the pressure is above the threshold.
  • Switches — pump, valve, interlocks. They change the colour of the button and the text.
  • Trend — pressure and flow for the last few seconds, with the alarm threshold drawn as a line. The window length comes from the configuration.
The simulation only runs while the instrument panel is visible. A hidden pane costs no frames.

Preferences

Edit > Preferences shows every setting of the configuration as a form: a search field, one row per setting with its title and description, and a control of the right type. The form is built from workbench.schema.json, so the documentation and the editor cannot describe different settings.

Changes that do not need a restart are applied at once: the theme, the alarm threshold, the trend window and the three switches. Save writes the file; Reset to defaults puts the defaults back in memory.

Configuration

Theme, toolbar, startup pane, startup switches, alarm threshold and trend length come from a JSONC file. See Configuration for the keys, the schema and an example.

Troubleshooting

SymptomCause
This page shows “no browser”The embedded browser needs a Chromium-family browser installed (Chrome, Chromium, Edge, Brave). Raven drives it headlessly.
The instrumentation does not moveThe panel is paused, or no pane with the panel is open. Press Resume / open the panel.
The Application page reports “defaults”The configuration file was not found or has a syntax error; the error and the line are shown there.
A switch does nothingAn action moves the plant only while the panel is visible; the switches themselves always work.
