User guide Configuration Shortcuts

Configuration

Settings come from a JSONC file: JSON with comments and trailing commas.

Editing it

Edit > Preferences (Ctrl+,) shows the same keys as a form, built from workbench.schema.json: search, titles, descriptions and a control of the right type. Save writes this file in place: only the values change, so your comments and layout stay as you wrote them, and a key that is missing is added. Reset to defaults puts the defaults back in memory. Changing the file by hand works too - it is read at the next start.

The schema

workbench.schema.json is a JSON Schema (2020-12) document that describes this file: groups, keys, types, choices, ranges and defaults. The Preferences pane is built from it, so a key that is not in the schema has no row, and a row always matches its documentation. The editor understands properties, title, description, type, enum, minimum, maximum and default; the rest of the document is for other editors and validators.

Which file

In this order:

  1. --config <path> on the command line,
  2. the WORKBENCH_CONFIG environment variable,
  3. workbench.jsonc, next to the application.

Every key is optional. A missing key keeps its default; a syntax error is reported on the Application page and the defaults are used.

Keys

KeyTypeDefaultEffect
release.channelstringdev shown on the Application page and the About box

simulation.chart_secondsnumber10 how much history the trend shows (1…10 s)

Example

{
	// a small plant, light, without the toolbar
	"release": { "channel": "beta" },

	"ui": {
		"theme": "light",
		"toolbar": false
	},

	"startup": {
		"pane": "instrument-panel",
		"pump": true,
		"valve": true,
		"armed": true
	},

	"simulation": {
		"alarm_limit": 50,
		"chart_seconds": 5
	}
}

Seeing what was read

The Application page shows the file that was used, whether it was found, and how many settings were applied. The status bar repeats it when the application starts.

The file is only read at startup: change it, then reopen the application. Writing it back from the interface is left as an exercise.
